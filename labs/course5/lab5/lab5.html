Lab 5 – Create hash values

Course 5 - Assets, Threats, and Vulnerabilities

Overview

In this lab, I practiced generating and comparing SHA‑256 hash values to verify file integrity. Hashing is a core cybersecurity skill used to detect tampering, confirm authenticity, and ensure that files have not been altered. By comparing two files and their hash outputs, I determined whether the files were identical or different.

Task 1 – List the Contents of the Home Directory

I began by listing the contents of the home directory. Two files were present:

  • file1.txt
  • file2.txt

These files were used to compare plaintext content and hash values.

Task 2 – Compare the Plaintext of Both Files

I used the cat command to display the contents of each file. Both files contained the EICAR antivirus test string, but file2.txt included additional characters at the end. Even small differences in plaintext should produce completely different hash values.

Task 3 – Compute SHA‑256 Hashes

I generated SHA‑256 hashes for both files using the sha256sum command. The resulting hashes were redirected into separate files:

  • file1hash
  • file2hash

Each hash file contained the computed hash followed by the filename.

Task 4 – Compare the Hash Values

I used the cmp command to compare the two hash files. The output indicated a difference at the first character of the first line, confirming that the hash values did not match. Because cryptographic hashes are extremely sensitive to input changes, even a single altered character results in a completely different hash.

Reflection

This lab demonstrated how hashing can be used to verify file integrity and detect tampering. Even though the two files appeared similar, their hash values revealed that they were not identical. Understanding how to generate and compare hashes is essential for malware analysis, digital forensics, and secure file verification.
