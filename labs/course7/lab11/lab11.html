Lab 11 – Create Another Algorithm

Course 7 - Automate Cybersecurity Tasks with Python

Lab Summary

In this lab, I developed a Python algorithm that reads an allow list file, identifies IP addresses that should no longer have access, removes them, and rewrites the updated list back to the file. I practiced converting file contents between strings and lists, iterating through IP addresses, applying conditional logic to filter out unauthorized entries, and automating the entire workflow inside a reusable function. This mirrors real-world cybersecurity automation used to maintain accurate access control lists.

Skills Demonstrated

  • Reading and writing text files using open(), .read(), and .write()
  • Parsing file contents with .split() and reconstructing them with .join()
  • Iterating through lists and removing elements conditionally
  • Building algorithms that update access control data
  • Encapsulating logic into a reusable Python function (update_file())
