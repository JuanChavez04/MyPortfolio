Lab 8 – Develop an Algorithm

Course 7 - Automate Cybersecurity Tasks with Python

Lab Summary

In this lab, I developed a Python algorithm that validates whether a user is approved to access a system and whether they have brought the correct assigned device. I worked with synchronized lists of usernames and device IDs, used list operations like append(), remove(), and index(), and built conditional logic to compare user input against approved data. I then combined these elements into a login() function that automates the entire verification process, demonstrating how algorithms support secure and efficient access control.

Skills Demonstrated

  • Building algorithms using step-by-step logical checks
  • Working with synchronized lists and list operations
  • Using append(), remove(), and index() for data management
  • Creating nested conditional statements
  • Developing and calling Python functions for automation
  • Implementing user and device validation logic
