Lab 5 – Define and Call a Function

Course 7 - Automate Cybersecurity Tasks with Python

Lab Summary

In this lab, I practiced defining and calling custom Python functions to make code reusable and easier to manage. I created an alert() function to standardize security warnings and then enhanced it with a loop to repeat alerts. I also built a list_to_string() function that iterates through a list of approved usernames, concatenates them into a single formatted string, and improves readability with separators. This reinforced how functions, loops, and string operations work together to automate repetitive security-related tasks.

Skills Demonstrated

  • Defining and calling user-defined Python functions
  • Using for loops inside functions
  • String concatenation and formatted output
  • Working with lists and iteration
  • Structuring reusable, readable Python code
