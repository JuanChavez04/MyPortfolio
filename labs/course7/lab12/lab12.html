Lab 12 – Update a file Through a Python Algorithm

Course 7 - Automate Cybersecurity Tasks with Python

Project Summary

In this project, I developed a Python algorithm that automatically updates an allow list by removing IP addresses that are no longer authorized. This simulates a real-world cybersecurity workflow where access control lists must be maintained accurately and efficiently through automation. The algorithm reads the file, parses its contents, removes unauthorized entries, and rewrites the updated list back to the file.

How the Algorithm Works

1. Open the allow list file

I assigned the file name to a variable and used a with open(..., "r") block to safely read the file contents into Python.

2. Read and parse the file

Using .read(), I imported the entire file as a string. Then I used .split() to convert the string into a list of individual IP addresses, making it possible to remove specific entries.

3. Remove unauthorized IP addresses

I iterated through the list and checked each IP against a remove_list. If an IP appeared in the remove list, it was removed from the allow list. This step demonstrates how loops and conditionals automate access control decisions.

4. Rewrite the updated allow list

After cleaning the list, I joined the IPs back into a single string and used with open(..., "w") to overwrite the file with the updated, authorized IP addresses.

Skills Demonstrated

  • File handling with open(), including read and write modes
  • Parsing and manipulating text data using .read(), .split(), and .join()
  • List operations such as iteration and .remove()
  • Conditional logic for access control automation
  • Building end-to-end algorithms for cybersecurity workflows
