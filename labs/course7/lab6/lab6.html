Lab 6 – Create More Functions

Course 7 - Automate Cybersecurity Tasks with Python

Lab Summary

In this lab, I worked with both built-in and user‑defined Python functions to analyze login activity. I used built‑in functions like max() to evaluate failed login attempts across months, and then created an analyze_logins() function that accepted parameters, calculated daily login ratios, returned values, and triggered alerts when activity exceeded normal levels. This lab strengthened my understanding of how functions, parameters, return statements, and conditionals work together to automate security analysis tasks.

Skills Demonstrated

  • Using built‑in Python functions for data analysis
  • Defining and calling user‑defined functions
  • Working with parameters and return values
  • Performing calculations inside functions
  • Using conditional logic to trigger alerts
  • Automating analysis of login activity
