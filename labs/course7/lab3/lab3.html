Lab 3 – Create a Conditional Statement

Course 7 - Automate Cybersecurity Tasks with Python

Lab Summary

In this lab, I practiced creating Python conditional statements to automate decisions related to system updates and user access. I used if, elif, and else to check which operating system was running, determine whether users were on an approved allow list, and verify if login attempts occurred during organization hours. I also combined multiple conditions with logical operators like and and in to produce concise, meaningful messages about login activity and access control, mirroring real-world authentication checks in cybersecurity.

Skills Demonstrated

  • Writing if, elif, and else conditional statements
  • Using logical operators such as and, or, and in
  • Checking user access against allow lists
  • Evaluating Boolean conditions for login timing and status
  • Designing concise, readable decision logic for security workflows
