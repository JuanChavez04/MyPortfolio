Lab 7 – Work With Strings in Python

Course 7 - Automate Cybersecurity Tasks with Python

Lab Summary

In this lab, I practiced working with strings in Python by converting numeric employee IDs into strings, validating their length, and updating them to meet new formatting requirements. I also extracted specific characters from a device ID using indexing and slicing, which helped reinforce how Python handles string positions. Finally, I worked with a URL and used slicing and the index() method to extract the protocol, domain extension, and website name. These exercises strengthened my ability to manipulate and analyze string-based data, which is essential for tasks like processing IDs, parsing logs, and examining network indicators in cybersecurity workflows.

Skills Demonstrated

  • Python string manipulation
  • Indexing and slicing
  • URL parsing
  • Data validation and formatting
