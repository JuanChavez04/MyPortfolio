Lab 2 – Assign Python Variables

Course 7 - Automate Cybersecurity Tasks with Python

Lab Summary

In this lab, I practiced assigning values to Python variables and inspecting their data types in the context of security-related data such as device IDs, allow lists, login limits, and login attempts. I worked with strings, lists, integers, and Booleans to represent users, access permissions, and login states, and used comparison operations to evaluate conditions like whether login attempts exceeded allowed thresholds. These exercises strengthened my understanding of how to model security concepts in code and laid the groundwork for building logic around authentication and access control.

Skills Demonstrated

  • Declaring and updating Python variables
  • Using type() to inspect data types
  • Working with strings, lists, integers, and Booleans
  • Modeling login attempts and access rules in code
  • Using comparison operators to evaluate security conditions
