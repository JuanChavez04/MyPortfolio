Lab 9 – Use Regular Expressions to Find Patterns

Course 7 - Automate Cybersecurity Tasks with Python

Lab Summary

In this lab, I used regular expressions in Python to extract meaningful security data from logs, including device IDs that match specific patterns and valid IP addresses. I practiced building regex patterns with symbols like \w, \d, +, and { } to control the precision of matches, and applied re.findall() to filter valid IPs from noisy log data. I then compared extracted IP addresses against a flagged list to automatically identify those requiring further investigation. This lab reinforced how regex can automate pattern detection in cybersecurity workflows.

Skills Demonstrated

  • Using Python’s re module for pattern matching
  • Building regex patterns with \w, \d, +, and { }
  • Extracting device IDs and IP addresses from log data
  • Validating IP address formats with quantifiers
  • Looping through extracted data to flag suspicious activity
  • Automating log analysis with regex and conditionals
