Lab 10 – Import and Parse a Text File

Course 7 - Automate Cybersecurity Tasks with Python

Lab Summary

In this lab, I practiced importing, reading, and parsing security log files using Python’s file-handling features. I used open() with read, write, and append modes to manage log data, converted file contents into strings and lists for easier analysis, and created a separate allow-list text file containing approved IP addresses. These skills support automated log processing and help streamline security workflows.

Skills Demonstrated

  • Reading and writing text files with open()
  • Using .read(), .write(), and .split() for file parsing
  • Appending missing log entries to existing files
  • Creating new text files for allow-lists
  • Preparing raw log data for further security analysis
