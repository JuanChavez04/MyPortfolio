Lab 1 – Practice Writing Python Code

Course 7 - Automate Cybersecurity Tasks with Python

Lab Summary

In this lab, I practiced writing basic Python code in a notebook environment, focusing on how to run code cells, use the print() function, and write comments to document intent. I explored the difference between executable code and non-executable comments, and combined multiple print statements to display a sequence of messages related to my role as a security analyst. This helped build a foundation for using Python to communicate clearly through code while keeping scripts readable and well-documented.

Skills Demonstrated

  • Using Python in a notebook-based environment
  • Writing and running print() statements
  • Creating and interpreting code comments
  • Combining multiple outputs in a single script
  • Understanding the difference between code and documentation
