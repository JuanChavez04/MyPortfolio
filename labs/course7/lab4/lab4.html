Lab 4 – Create Loops

Course 7 - Automate Cybersecurity Tasks with Python

Lab Summary

In this lab, I practiced creating loops in Python to automate repetitive security-related tasks. I used for and while loops to display network connection messages, iterate over IP address lists, and generate sequential employee IDs within a defined range. I also combined loops with conditionals and the break statement to stop processing when suspicious activity was detected, reinforcing how iterative logic supports efficient monitoring and control in cybersecurity workflows.

Skills Demonstrated

  • Writing for and while loops in Python
  • Using range() and loop counters for repetition
  • Iterating over lists of IP addresses
  • Combining loops with conditional logic (if/else)
  • Using in and break for access checks and early termination
  • Generating and managing sequential ID values
