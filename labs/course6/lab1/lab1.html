Lab 1 – Analyze Your First Packet

Course 6 - Sound the Alarm: Detection and Response

Overview

In this activity, I analyzed network traffic using Wireshark to understand how data moves between systems during a web browsing session. Packet capture analysis is an essential skill for security analysts because it helps identify communication patterns, detect anomalies, and investigate suspicious activity. I used Wireshark to inspect packet details, apply filters, and examine specific protocols such as DNS, TCP, and HTTP.

Scenario

As a security analyst, I investigated traffic related to a user connecting to a website. The packet capture file contained multiple protocols and communication flows. My task was to filter the data to identify source and destination IP addresses, examine protocol behavior, and analyze packet contents to understand what information was exchanged during the session.

Identifying Source and Destination IP Addresses

I applied filters to isolate traffic between the user’s machine and the destination server. This allowed me to identify the IP addresses involved in the session and observe the sequence of packets exchanged during the connection process.

Examining Protocol Layers

I inspected individual packets to review Ethernet, IP, and TCP headers. This helped me understand how the connection was established, including SYN, SYN-ACK, and ACK packets. Examining protocol layers also revealed port numbers, flags, and sequence values used during the session.

Filtering DNS Traffic

I applied a filter for UDP port 53 to isolate DNS queries and responses. This allowed me to identify the domain being resolved and the IP addresses returned by the DNS server. DNS analysis is important because attackers often manipulate DNS to redirect users or hide malicious activity.

Filtering TCP Port 80 (HTTP Traffic)

I filtered for TCP port 80 to examine HTTP communication. This revealed packets associated with web requests and responses. Reviewing HTTP traffic helps analysts understand what data is being sent to and from a website, including headers and payloads.

Searching for Specific Payload Text

I used the filter tcp contains "curl" to locate packets containing specific text in their payload. This technique is useful for identifying command-line activity, API calls, or suspicious strings within network traffic.

Reflection

This activity strengthened my ability to analyze packet captures and apply targeted filters to isolate relevant traffic. Understanding how to inspect DNS, TCP, and HTTP packets is essential for detecting malicious behavior, troubleshooting network issues, and validating normal communication patterns. Wireshark provides deep visibility into network activity, making it a critical tool for cybersecurity investigations.
