Lab 2 – Capture Your First Packet

Course 6 - Sound the Alarm: Detection and Response

Overview

In this lab, I used tcpdump in a Linux environment to capture, filter, and analyze network traffic. Understanding how to work with network interfaces and packet capture tools is essential for security analysts because it allows them to observe live traffic, identify communication patterns, and investigate suspicious activity.

Scenario

Acting as a network analyst, I used tcpdump to capture live traffic from a Linux virtual machine. I identified available network interfaces, captured packets in real time, saved traffic to a packet capture file, and analyzed the captured data to understand the communication between systems.

Identifying Network Interfaces

I began by listing the available network interfaces using ifconfig and tcpdump -D. This allowed me to determine which interface was active and appropriate for capturing traffic. In this environment, eth0 was the primary interface used for network communication.

Capturing Live Network Traffic

Next, I used tcpdump to capture a small number of packets from the eth0 interface. The verbose output displayed details such as IP addresses, protocols, flags, and sequence numbers. This step demonstrated how tcpdump captures and displays live traffic in real time.

Capturing HTTP Traffic to a File

I then filtered traffic on port 80 (HTTP) and saved the captured packets to a file named capture.pcap. While the capture was running in the background, I generated HTTP traffic using a curl request. After the capture completed, I verified that the file was successfully created.

Analyzing the Packet Capture File

After capturing the traffic, I used tcpdump -r to read and analyze the capture.pcap file. The output revealed the TCP handshake, HTTP request, and communication between the client and the server. This step demonstrated how to inspect captured traffic offline.

Deep Packet Inspection

I also viewed the packet contents in both hexadecimal and ASCII using the -X option. This provides a deeper look into the raw data being transmitted, which is useful for analyzing payloads, headers, and protocol behavior.

Reflection

This lab strengthened my ability to capture and analyze network traffic using tcpdump. I practiced identifying interfaces, filtering traffic, saving packet captures, and analyzing both high-level and low-level packet details. These skills are essential for network troubleshooting, incident response, and security investigations.
