Lab 3 – Find Files with Linux Commands

Course 4 - Tools of Trade: Linux and SQL

Overview

In this lab, I practiced navigating a Linux file system, locating files, and reading file contents using basic Bash commands. I used commands such as pwd, ls, cd, cat, and head to explore directories and inspect text files. These skills are essential for working efficiently in Linux environments, especially in cybersecurity and system administration.

Task 1 – Find the Current Working Directory

I used the pwd command to display my current working directory. This helped confirm my location in the file system before navigating further.

Task 2 – Display Directory Contents

I used the ls command to list files and subdirectories. This allowed me to see which folders and files were available in the current directory.

Task 3 – Navigate to a Directory

I used the cd command to move into different directories. When I mistyped a directory name, the shell returned an error, which reinforced the importance of accurate command input.

Task 4 – Display the Contents of a File

I used the cat command to display the full contents of a text file. This allowed me to review user data stored in Q1_added_users.txt.

Task 5 – Display the First 10 Lines of a File

I used the head command to view the first 10 lines of server_logs.txt. This is useful for quickly checking log files without scrolling through the entire file.

Reflection

This lab helped reinforce how to navigate the Linux file system and inspect files using essential Bash commands. Understanding how to move between directories, list contents, and read files is foundational for any technical role involving Linux systems.
