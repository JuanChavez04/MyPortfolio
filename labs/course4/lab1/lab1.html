Lab 1 – Installing Software in a Linux Distribution

Course 4 - Tools of Trade: Linux and SQL

Overview

In this lab, I practiced installing, uninstalling, and verifying software packages in a Linux distribution using the APT package manager. I worked with two cybersecurity tools: Suricata and tcpdump. This activity helped me understand how Linux handles package installation, dependencies, and system verification through command‑line tools.

Task 1 – Confirm APT is Installed

I confirmed that the APT package manager was available by running a basic APT command. This verified that the system was ready for software installation and management.

Task 2 – Install and Uninstall Suricata

I installed Suricata using the command: 

sudo apt install suricata

The terminal displayed the list of dependencies and installation progress. After verifying the installation, I uninstalled Suricata using: 

sudo apt remove suricata

Task 3 – Install tcpdump

Next, I installed tcpdump, a command‑line packet capture tool, using: 

sudo apt install tcpdump

The installation completed successfully, and the lab system confirmed the task.

Task 4 – Verify Installed Applications

I used the following command to list installed applications: 

apt list --installed

I confirmed that tcpdump appeared in the list, while Suricata did not (because it had been removed earlier).

Task 5 – Reinstall Suricata

I reinstalled Suricata using: 

sudo apt install suricata

After reinstalling, I again used apt list --installed to confirm that both suricata and tcpdump were installed.

Reflection

This lab helped me understand how Linux manages software installation, dependencies, and system verification. I gained hands‑on experience using APT to install, remove, and audit applications—skills that are essential for system administration and cybersecurity operations.
