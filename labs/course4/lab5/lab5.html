Lab 5 – Managing Files with Linux Commands

Course 4 - Tools of Trade: Linux and SQL

Overview

In this lab, I practiced managing files and directories in a Linux environment using Bash commands. I created and removed directories, moved and deleted files, and used the nano text editor to add content to a file. These tasks helped reinforce essential Linux file‑system operations used in system administration and cybersecurity workflows.

Task 1 – Create a New Directory

I used the mkdir command to create a new directory. This is useful for organizing files and structuring project folders.

Task 2 – Remove a Directory

I removed an empty directory using the rmdir command. This demonstrated how Linux handles directory deletion and the difference between removing files and removing folders.

Task 3 – Move and Delete Files

I used the mv command to move a file from one directory to another. Then I used the rm command to delete an unnecessary file. These commands are essential for managing file organization and cleaning up unused data.

Task 4 – Create a File and Add Text Using nano

I created a new file using the touch command and then opened it in the nano text editor. Inside nano, I added a note describing the tasks I completed during the lab. This demonstrated how to edit files directly from the terminal.

Reflection

This lab strengthened my understanding of Linux file‑system management. I gained hands‑on experience creating, moving, and deleting files and directories, as well as editing text files using nano. These skills are foundational for working in Linux‑based environments and are widely used in cybersecurity, DevOps, and IT operations.
