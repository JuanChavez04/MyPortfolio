Lab 4 – Filter with Grep

Course 4 - Tools of Trade: Linux and SQL

Overview

In this lab, I practiced using the grep command to search for specific strings inside files and filter information efficiently. I worked with quarterly user reports and log files to locate usernames, departments, and other important data. This lab strengthened my ability to extract meaningful information from text files using Linux command-line tools.

Task 1 – Search for Error Messages in a File

I used the grep command to search for error messages inside log files. This demonstrated how grep can quickly filter relevant lines without manually scrolling through the entire file.

Task 2 – Search for Files Containing a Specific String

I used grep to search across multiple files for specific keywords. This is useful when working with large directories or when trying to locate files that contain certain information.

Task 3 – Search for Information in User Files

I navigated into the reports/users directory and used grep to extract specific user information from quarterly reports. For example, I searched for deleted users and new hires in different departments.

Reflection

This lab helped me understand how powerful grep is for searching through logs and structured text files. Being able to filter information quickly is essential for cybersecurity work, especially when analyzing logs, user activity, or system events. I also reinforced my skills in navigating directories and working with multiple files in the Bash shell.
