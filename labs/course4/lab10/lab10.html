Lab 10 – Perform a SQL Query

Course 4 - Tools of Trade: Linux and SQL

Overview

In this lab, I practiced retrieving information from a MariaDB database using SQL queries. I explored how to return specific columns, filter data, and sort results. These skills are essential for analyzing organizational data, investigating login activity, and reviewing device information.

Task 1 – Return Information on Employee Devices

I queried the machines table to return device information such as device IDs, operating systems, email clients, patch dates, and employee IDs. This helped me understand how device data is structured in the database.

Task 2 – Examine Login Attempts

I queried the log_in_attempts table to review login activity. This included usernames, timestamps, IP addresses, countries, and whether the login attempt was successful. This type of query is useful for monitoring authentication behavior and identifying suspicious activity.

Task 3 – Sort Data Returned from a Query

I used the ORDER BY clause to sort query results. Sorting helps reveal patterns, such as login sequences or device usage trends. I also practiced selecting specific columns to return only the data needed for analysis.

Reflection

This lab strengthened my understanding of SQL fundamentals, including selecting data, sorting results, and retrieving specific fields. These skills are essential for analyzing organizational data, supporting investigations, and working with relational databases in cybersecurity environments.
