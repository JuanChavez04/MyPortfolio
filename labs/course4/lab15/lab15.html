Lab 15 – Complete a Join

Course 4 - Tools of Trade: Linux and SQL

Overview

In this lab, I used INNER JOIN, LEFT JOIN, and RIGHT JOIN to combine data from multiple tables in a MariaDB database. These joins allowed me to connect employee information, machine details, and login activity to better understand how data relates across the organization.

Task 1 – Use an INNER JOIN to Find Information on Employees and Their Machines

I used an INNER JOIN to combine the machines and employees tables based on matching device_id values. This join returns only the rows where both tables contain matching device IDs, allowing me to see which employees are assigned to which machines.

Task 2 – Use LEFT JOIN and RIGHT JOIN to Compare Machine and Employee Records

I used a RIGHT JOIN to return all employees, including those who do not have a matching device in the machines table. This is useful for identifying employees who may not have a registered machine or whose device information is missing.

LEFT JOIN was also explored conceptually in this lab, which would return all machines even if some do not have an assigned employee. This helps identify unused or unassigned devices in the organization.

Task 3 – Use an INNER JOIN to Find Information on Employees and Their Login Attempts

I used an INNER JOIN between the employees and log_in_attempts tables using the username field. This allowed me to connect each login attempt to the employee who performed it, which is essential for investigating suspicious login activity.

Reflection

This lab helped me understand how SQL joins can be used to connect related data across multiple tables. INNER JOIN allowed me to focus on matching records, while RIGHT JOIN helped identify missing machine assignments. These techniques are essential for cybersecurity investigations, asset tracking, and analyzing authentication patterns.
