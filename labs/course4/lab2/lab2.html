Lab 2 – Examining Input and Output in the Shell

Course 4 - Tools of Trade: Linux and SQL

Overview

In this lab, I explored how the Linux shell handles input and output using basic commands. I used the echo command to generate output, the expr command to perform simple calculations, and the clear command to reset the terminal window. These exercises helped reinforce how the Bash shell processes text, numbers, and user input.

Task 1 – Generate Output with echo

I used the echo command to print text to the terminal. This demonstrated how the shell receives input and returns output. I tested echo with and without quotation marks to see how the shell interprets strings.

Task 2 – Perform Basic Calculations with expr

I used the expr command to perform arithmetic operations such as subtraction and multiplication. This showed how Bash can evaluate expressions directly in the terminal.

Examples I ran: 

expr 32 - 8 expr 3500 \* 12

Task 3 – Clear the Shell Window

To reset the terminal display, I used the clear command. This removes previous output from the screen and provides a clean workspace for new commands.

Task 4 – Explore Additional Commands

I experimented with other basic shell commands to better understand how Linux handles input, output, and command execution. This helped build confidence in navigating and interacting with the Bash environment.

Reflection

This lab helped reinforce how the Bash shell processes text, evaluates expressions, and displays output. Understanding these fundamentals is essential for working efficiently in Linux, especially when performing system administration or cybersecurity tasks.
