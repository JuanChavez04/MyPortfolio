Lab 8 – Add and Manage Users with Linux Commmands

Course 4 - Tools of Trade: Linux and SQL

Overview

In this lab, I practiced adding users, modifying user access, assigning group membership, and removing users from a Linux system. These tasks are essential for managing authentication and ensuring that users have the correct permissions in a secure environment.

Task 1 – Add a New Employee

I created a new user account using the useradd command. This is the first step in onboarding a new employee and giving them access to the system.

Task 2 – Change Ownership of a File

I used the chown command to assign ownership of a file to the new user. This ensures that the employee has the correct permissions to work with the files they are responsible for.

Task 3 – Add the Employee to a Group

I added the new user to an additional group using usermod -a -G. Group membership determines what shared resources the user can access.

Task 4 – Delete the Employee from the System

I removed the user account using userdel. I also removed the user’s associated group when necessary. This step is important when an employee leaves the organization or no longer needs system access.

Reflection

This lab helped me understand how Linux handles user accounts and group permissions. I practiced creating users, modifying their access, assigning them to groups, and removing them when necessary. These skills are essential for managing authentication and maintaining secure access control in a Linux environment.
