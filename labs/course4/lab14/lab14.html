Lab 14 – Perform a SQL Query

Course 4 - Tools of Trade: Linux and SQL

Overview

In this lab, I practiced applying filters to SQL queries to retrieve specific information from a database. I used the MariaDB shell to filter employee records, machine data, and department information. These filtering skills are essential for analyzing organizational data and answering targeted questions using SQL.

Return Information on Machines and Their Operating Systems

I queried the machines table to return device information and operating systems. This helped me understand how machine data is stored and how to retrieve specific fields from a table.

Filter for Machines with a Specific Operating System

I used the WHERE clause to filter machines by operating system. This allowed me to narrow down the dataset to only the machines running a particular OS.

Filter for Employees in Specific Departments

I filtered the employees table to return only employees in certain departments, such as Sales and Finance. This demonstrated how SQL can isolate specific groups of employees based on department data.

Filter for Employees Who Use Specific Machines

I filtered employees by office location using pattern matching with the LIKE operator. This allowed me to return all employees whose office names began with “South”.

Reflection

This lab strengthened my understanding of SQL filtering techniques, including equality filters, pattern matching, and correcting syntax errors. These skills are essential for retrieving meaningful insights from relational databases and supporting data-driven decision-making in cybersecurity and IT environments.
