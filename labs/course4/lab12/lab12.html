Lab 12 – Applying More filters in SQL

Course 4 - Tools of Trade: Linux and SQL

Overview

In this lab, I practiced applying additional SQL filters to retrieve specific login activity from a database. I used comparison operators, date ranges, and time filters to analyze login attempts. These skills are essential for investigating authentication patterns and identifying unusual activity.

Task 1 – Filter for Login Attempts Made After a Certain Date

I used the WHERE clause with a greater‑than operator to return login attempts that occurred after a specific date. This is useful for narrowing down recent activity or focusing on a particular investigation window.

Task 2 – Filter for Login Attempts in a Date Range

I used the BETWEEN operator to return login attempts within a specific date range. This helped isolate activity between May 9 and May 11.

Task 3 – Filter for Login Attempts at a Certain Time

I filtered login attempts by time using BETWEEN on the login_time column. This allowed me to analyze activity that occurred between 06:00 and 07:00.

Task 4 – Filter for Login Attempts by ID

I filtered login attempts by event ID using a comparison operator. This returned all login attempts with an event ID of 100 or greater.

Reflection

This lab strengthened my ability to apply SQL filters using comparison operators, date ranges, and time ranges. These techniques are essential for analyzing authentication logs, identifying suspicious behavior, and extracting meaningful insights from relational databases.
