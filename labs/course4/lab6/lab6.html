Lab 6 – Managing Authorization

Course 4 - Tools of Trade: Linux and SQL

Overview

In this lab, I learned how to examine and modify file permissions in Linux. These skills are essential for configuring user authorization and ensuring that files and directories have the correct access levels. I used the ls -l command to inspect permissions and the chmod command to correct or restrict access where needed.

Task 1 – Check Permissions for Files in a Directory

I used the ls -l command to view the permissions of all files in the projects directory. This allowed me to identify which files had incorrect or overly permissive access settings.

Task 2 – Correct Incorrect File Permissions

I used the chmod command to adjust permissions for specific files. For example, I removed write permissions for “others” on one file and removed read permissions for the group on another. This ensured that only authorized users could modify or view sensitive files.

Task 3 – Remove Unauthorized Access to a Directory

I restricted access to the drafts directory by modifying its permissions. This prevented unauthorized users from executing or accessing the directory contents, improving overall security.

Reflection

This lab helped me understand how Linux handles file permissions and how to modify them using symbolic and numeric modes. Being able to identify incorrect permissions and correct them is a critical skill for maintaining secure systems and preventing unauthorized access.
